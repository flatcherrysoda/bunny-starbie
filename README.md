# design
This project was my first time working with Kicad and design a pcb. I went for a pixel bunny shaped design. It was kind of hard to arrange all the items in the bunny shape. My first plan was to put all the items on the side and add a large image on the right, but that made it hard to route everything. So, I moved them around. But also it took me WAYYYY to long to realize that you could route on the back, and after I figured that out it was easier. Lastly I add some cute bunny images I found to the silkscreen to match the outline.
